Comment obtenir un token API :

  1. Ouvrez Microsoft Teams
  2. Allez dans Paramètres > Confidentialité
  3. Activez "Permettre aux applications tierces d'accéder aux informations de réunion"
  4. Copiez le token généré et collez-le ci-dessus

Utilisation :

  • Cliquez sur le bouton pour changer le mode d'affichage
  • L'icône se met à jour automatiquement avec l'état Teams
  • Rouge = Muet/Caméra arrêtée/Hors réunion
  • Normal = Audio/Caméra/En réunion
